# PortCanvas Demo V0.4 使用说明

原 Wheel Combat Studio 的 Tauri 2 / Rust / WebView2 迁移版。设备管理、远程桌面、文件传输、右侧持久终端和电脑本地日志保留；新增旧版资料导入与回退。Logo使用用户提供的PortCanvas图案，应用图标及侧栏均使用方形资源。

## 安装与便携

交付目录`demo-v0.4/`内包含Windows x64安装包和`portable/`。安装包按当前用户安装，开始菜单入口为PortCanvas。便携版解压到可写目录，双击PortCanvas.exe；同目录portable.flag启用便携模式，也可手动传入`--portable`。保留THIRD-PARTY-NOTICES.txt。

客户端需要Microsoft Edge WebView2运行时，安装包可在缺失时下载部署；便携包使用电脑现有运行时。运行应用不需要安装Node、Rust、Electron或Python。源码构建另需相应工具链。本轮实测Windows 11 x64；不将此结果当作其他系统已验收。

普通安装的设备资料位于当前用户应用数据目录`io.portcanvas.app`，不写入Program Files。便携模式资料与WebView缓存位于同目录`data/`，默认日志在`data/logs/`。普通模式日志优先沿用已存在的“文档/Wheel Combat Studio/Logs”，否则使用“文档/PortCanvas/Logs”；已有日志设置优先。日志页显示实际位置，可更换目录。

## 从V0.3.5迁移

1. 保留旧版完整目录。关闭旧版设备连接，在PortCanvas设备页点击“导入旧版资料”。
2. 选择旧版EXE旁包含devices.json的data目录；开发版可选择原studio-data目录。
3. 核对预览中的来源、目标、新增设备/指纹数量及日志位置，确认后才写入。设备ID和受信指纹保持，原配置另做备份；旧目录和日志原文不修改、不搬移。
4. 如需回退，先断开设备，点击“恢复导入前资料”，选择本应用数据目录migration-backups下对应的备份目录。回退前再次备份当前配置；回退不删除日志。

设备ID或主机指纹冲突、无效配置、确认期间外部修改会停止导入，原件保留。不要用手工替换指纹绕过真实身份变化；需先查清设备重装或地址变化原因。

## 连接与桌面

填写地址、SSH端口、Linux用户名和密码；密码只用于当前连接。首次连接核对SHA256指纹，取消不会保存信任。核对指纹的等待不消耗网络超时；正常网络连接仍有超时和取消。

桌面使用目标设备已有X11会话，经SSH加密转发VNC；支持鼠标键盘、只读、适配/原始尺寸和全屏。关闭桌面不关闭SSH/SFTP/终端。需要目标设备可用的X11授权和x11vnc。当前控制器兼容已有私有x11vnc部署；其他Linux优先使用系统x11vnc。Wayland、Windows远端和NX协议不在本版验收范围。

## 文件传输

文件页左侧为电脑、右侧为远端，支持目录浏览、新建目录、文件/文件夹上传下载、空目录、进度、限速、取消和覆盖确认。先选来源条目，再选择目标目录。上传覆盖需服务器支持OpenSSH posix-rename扩展；不支持时保留原文件并报错。

传输先写本次临时文件，成功后发布；取消或断线不会将半成品当成最终目标。重连只回收本次登记的临时路径。本版不提供断点续传或崩溃后的通用临时文件扫描。链接和特殊文件不跟随传输。

## 持久终端与日志

设备页之外可用右上“终端”打开右侧栏。连接/恢复终端后直接输入命令。收起侧栏、切换页面或断开终端不会结束tmux内的程序；SSH断线、退出电脑软件后，重新连接可恢复同一会话。设备关机、重启、程序自身退出或手工结束tmux不属于存活保证。

每条前台命令记录项目、日期、工作目录、文本输出、结束状态和退出码；默认按远端Git项目/目录识别，也可在终端栏手动指定项目名，对后续命令生效。后台和交错输出另存会话记录。日志由独立通道采集，断开终端显示后仍可继续记录。

日志全部保存在电脑，格式保持`项目/日期/运行ID/run.json + output.log`，UTF-8，兼容`wcs.run/1`，便于AI或调试者直接读取。SSH断线期间无法接收的文本明确标注缺失，重连可续写同一运行ID，但不会把有缺失的记录标成完整。应用异常退出后也会识别旧记录为中断。

日志页支持项目/日期/状态筛选、每页200条、详情末尾256KiB预览及打开完整文件所在目录。预览截断不裁剪磁盘原文。清理只删除选中的本地已结束/中断记录，需确认，运行中的记录保留。更换日志位置前先断开设备并等待封存；旧目录文件保留。

## 版本边界

实时擂台保留入口，接口实时数值、摄像头、AI、插件运行时及V0.5功能仍按后续路线推进。具体测试证据、测量环境和资源数据见本版验收记录；不以短时测试承诺任意网络和长期运行永无故障。
