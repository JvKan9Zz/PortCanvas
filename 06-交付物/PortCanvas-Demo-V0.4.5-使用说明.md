# PortCanvas Demo V0.4.5

Windows x64 安装包：`demo-v0.4.5/PortCanvas_0.4.5_x64-setup.exe`。便携版：`demo-v0.4.5/portable/PortCanvas.exe`；将整个 portable 目录放到可写位置后运行，保留 portable.flag。电脑端使用系统 WebView2，无需安装 Node、Rust 或 Python。

## 本次更新

- 全部当前应用标志改为用户指定的透明底 PC Logo，包括侧栏、窗口、任务栏、安装程序、桌面快捷方式与仓库主页。PNG 和 ICO 画布均为正方形，等比缩放，不加黑底。旧品牌源文件保留作历史资料。
- 设备页可切换密码或 SSH 密钥认证。私钥支持 OpenSSH、PEM、PuTTY PPK；选择本机私钥文件，加密私钥输入密钥口令，未加密私钥留空。远端需先为登录用户授权对应公钥；软件不自动部署公钥。
- “记住密码 / 记住密钥口令”默认不勾选。勾选后保存配置或连接时，使用当前 Windows 账户的 DPAPI 加密保存在本机。再次打开可留空使用；取消勾选并保存即移除。更换主机、端口、用户名、认证方式或密钥路径后需重新提供凭据。私钥内容不写入配置，仅记录路径。
- 文件页本地地址栏左侧增加盘符下拉框，可直接切换 C、D 等当前可用盘符；不需要先连接远端。路径输入、上级目录和选择目录仍可使用。

## 数据与兼容

正常安装的数据位于 `%APPDATA%/io.portcanvas.app`；便携模式位于同目录 data。日志页面显示实际日志根目录，日志仍全部保存在电脑。升级沿用 V0.4 设备和主机指纹；V0.3.5 资料通过设备页“导入旧版资料”迁移，支持预览和回退。

记住凭据绑定当前 Windows 账户及设备身份，复制配置到其他电脑或账户后不能保证解密，应重新输入。取消保存不会删除用户自行保管的私钥。密码和密钥口令不进入运行日志、仓库或交付包。

远程桌面、双向 SFTP、右侧持久终端和本地运行日志沿用 V0.4。终端由远端 tmux 承载；断线不主动结束程序，设备重启或程序退出则不能保证继续。离线未收到的日志明确标记缺失。

当前验收环境为 Windows 11 x64 和创意之星 AI 控制器的 Ubuntu 20.04.6 / ARM64。其他平台未完成实机验收。完整框架与迁移说明见 V0.4 使用说明；本次验证范围见同目录 V0.4.5 验收记录。
