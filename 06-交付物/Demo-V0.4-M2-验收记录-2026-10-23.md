# Demo V0.4 M2：Rust 连接与桌面

M2 工作包完成，M3–M5 仍在继续；尚非正式完整 V0.4 发布包。M0/M1 为独立前置 PR #3。

| 验证 | 结果 |
| --- | --- |
| Rust 核心 | 4 项测试通过，包含旧设备/指纹/会话名、过期状态不能覆盖新连接、Python 参数编码；Tauri 构建和 TypeScript 检查通过 |
| 身份与错误 | 隔离资料中的错误受信指纹被拒绝，原信任不改；认证失败可重试，正确设备连接成功；字符串错误统一转换后界面保留具体原因 |
| 桥接范围 | 本地端口只绑定127.0.0.1，随机路径；错误Origin实测403；单个活动客户端；二进制流式转发，无Electron/Node运行核心 |
| 真实桌面 | 目标Linux/X11上创建本轮临时输入窗口，实际鼠标与按键经WebView2/noVNC/Rust SSH到达；只读阻止输入，适配/1:1/全屏切换通过 |
| 生命周期 | 停桌面保留SSH；取消/断开期间的旧请求不污染新连接；再次连接恢复；仅本次x11vnc进程结束，原基线进程保持 |
| 强制结束 | 实际终止原生Windows进程时，远端本轮x11vnc由1个恢复为0，无残留 |

证据：本项目 local/v04/m2-core-test.txt、m2-live-result.json、m2-desktop.png、m2-crash-result.json。真实测试仅GUI输入窗口和桌面共享，不涉及SDK、视觉采集、传感器或车辆动作。

关闭修复：首次实测发现一个本轮x11vnc成为PPID1的孤儿进程。先核实精确PID和可执行路径，清理自身残留；Rust先发送EOF并等待远端结束再关闭通道；Python有界终止/等待，必要时结束自己创建的子进程，Linux子进程绑定父进程死亡信号。修复后完整实机检查与主程序强制结束检查通过。

通用性：桌面后端优先使用远端系统x11vnc；旧控制器私有部署作为兼容回退，库目录按远端MULTIARCH识别。SSH/设备状态与桌面服务独立。当前实测目标为现有Ubuntu/X11控制器，不宣称Wayland或Windows远端支持。

回退：M2分支独立于main，保留V0.3.5完整工程与交付。首次信任的原生确认、安装/迁移与完整并行资源对照仍需M5全功能发布包复核；本包不以原型资源样本证明轻量化收益。
