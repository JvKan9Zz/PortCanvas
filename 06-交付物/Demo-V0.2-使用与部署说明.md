# Wheel Combat Studio · Demo V0.2

在 V0.1 的设备连接与远程桌面基础上，新增 SFTP 文件管理传输。实时擂台保留后续版本入口。

## 启动与连接

解压完整交付包，运行目录中的 `Wheel Combat Studio.exe`，保留整个文件夹。无需另装 Node.js 或开发服务器。也可直接使用本项目 `demo-v0.2/win-unpacked/` 中的 EXE。

在设备页填写地址、SSH 端口、用户名和本次密码，连接成功后打开左侧“文件”。当前设备配置已复制到新版；密码只留在本次窗口内存，关闭后清除。配置存放于 EXE 同目录 `data/devices.json`。

SFTP 直接使用现有 SSH 连接，无需在树莓派新增文件传输服务。已有远程桌面组件和连接用法与 V0.1 相同，沿用板端私有运行时；切换文件页不会关闭桌面。

## 浏览和传输

左栏是本地电脑，右栏是树莓派。地址栏输入目录并回车；双击文件夹进入，工具栏可返回上一级、主目录或刷新。本地“选择目录”可以选其他磁盘/目录。

点击行或复选框选择项目，Ctrl+点击可追加选择，表头复选框全选当前目录。选左栏后点击“上传至树莓派”，目标是右栏当前目录；选右栏后点击“下载至电脑”，目标是左栏当前目录。文件夹会递归传输，包含空文件夹，合并到目标同名目录，保留目标中额外的文件。

两栏各有“新建文件夹”。已有同名文件会弹出原生覆盖确认，列出目标路径；取消会终止整批传输，覆盖后才开始写入。文件与文件夹类型冲突会报错。名称不符合 Windows 规则的远端文件、符号链接和特殊文件会明确报错，本版不静默跳过它们。

## 进度、限速与取消

状态区显示当前文件、目标目录、已传字节、文件数量和速度。限速可选不限速、1/5/10 MiB/s，设置在本次传输开始时生效。一次执行一批传输。

点击“取消传输”不会断开设备或远程桌面。已经完成的文件保留，当前尚未完成的数据留在临时文件中并尝试清理。文件传完并关闭后才发布为最终目标，因此不会把半个文件直接当成完整文件覆盖。失败后可修正目录/权限并重新发起；本版从头传输，不提供断点续传。

若网络中断，错误中可能列出 `.wcs-transfer-UUID.part` 临时文件。当前软件会话重新建立 SFTP 时会重试清理精确登记的本次临时路径。软件崩溃或直接关闭后可能留有这类临时文件，它们不是完整交付文件；需要时可在文件管理器中核实处理。本版同步文件内容，不同步原始时间戳、Unix 权限或链接。

## 开发与验证

源码在 `03-实现与脚本/studio`，使用 `npm ci`、`npm run runtime`、`npm start`；测试 `npm test`，打包 `npm run pack`。Windows 命令入口遵守工作区 PowerShell 7 / Bash 规则。

本次已有 16/16 自动测试、真实板端 SFTP 内容哈希与异常检查、交付 EXE 的实际 UI 流程及桌面回归。具体证据和未测范围见同目录验收记录。V0.1 历史交付保留于 demo-v0.1。
