# PortCanvas Demo V0.5.0 使用说明

本版新增赛台页面，保留既有设备、桌面、文件、终端、日志和设置功能。

## 赛台与性能

连接设备后点击左侧“赛台”。左侧上方为远端摄像头，下方显示该设备的 CPU、内存、交换空间、运行时间、系统负载、网卡收发速率和最近60秒 CPU/内存曲线。首个采样不虚构 CPU/网络速率；断连或读取失败清空过期读数。SSH往返包含远端采样与处理耗时，并非 ICMP ping。

右侧采用毫米坐标，围墙内3.8×3.8m，中央台面2.4×2.4m，两侧台下各0.70m。围墙以红线警示；出发区按规则绘制。台面使用用户提供打印图的1024px显示贴图，原图保留。尺寸依据2026 RoboCup总决赛规则第10–11页。

车辆定位、敌车和能量块未接入，页面明确标识定位不可用，不显示模拟位置。窄窗口或展开终端时布局适配可用宽度，必要时滚动查看。

## 摄像头开关

摄像头默认关闭。选择视频设备后，点击“开启摄像头”；不需要时点击“关闭摄像头”。关闭会停止本次采集并释放设备。切离赛台、最小化、断开设备、关闭客户端也会停止视频；返回页面或恢复窗口后需手动开启。

视频通过现有 SSH 的独立通道传输，不新增公开端口、不录像、不保存视频文件。预览上限640×480、最高8帧/秒；实际帧率取决于摄像头、设备和网络。原生端只保留最新一帧，前端替换并释放旧图片。

远端需要 Linux V4L2、Python3 和可导入的 OpenCV（cv2）；本次已在用户控制器的 Ubuntu20.04.6、Python3.8、OpenCV4.10、HD USB Camera /dev/video0 验证。普通电脑端安装无需 Python 或 Node。未验证标准 Raspberry Pi 的 CSI/libcamera 接入，不将本控制器称谓推定为特定硬件型号。

预览可能独占相机。若比赛程序或其他软件正在使用摄像头，先关闭相应预览或程序，再重试；本软件不终止其他软件的采集进程。网络中断时通过通道关闭及心跳超时释放本软件采集；远端看门狗15秒无心跳退出，前端停止消费时原生端也会停止采集。

## 安装与资料

Windows x64 安装包：`PortCanvas_0.5.0_x64-setup.exe`。便携包目录中的 `PortCanvas.exe` 可直接运行，需系统 WebView2。

安装模式使用当前用户原有应用资料；便携模式由同目录 `portable.flag` 启用，在同目录 `data/` 保存配置、缓存及默认日志。升级前会备份当前配置，保留设备、主机指纹、终端与日志设置。请勿将个人 `data/`、私钥、凭据或运行日志上传到公共仓库。

本次为 Windows11 x64 + 创意之星 AI 控制器实机验收；其他 Linux 摄像头或桌面平台未完成实机验证。
