# PortCanvas Demo V0.4.7

本版增加多终端、手动重启和关闭终端；移除输入画面中的绿色tmux状态栏，并统一清屏按钮样式。沿用V0.4.6的本地滚轮、可调宽侧栏、动画及透明Logo。

连接设备后，在设备页以外打开右侧终端栏。点击“新建”建立独立终端，点击标签切换；每个终端有独立Shell、输入、画面和日志项目。标签可横向滚动，聚焦标签后可用左右方向键、Home/End切换。

| 操作 | 结果 |
| --- | --- |
| 清屏 | 清理当前终端的本机显示，不删除日志，不终止程序 |
| 断开 | 脱离当前终端显示，远端程序保留，可连接/恢复；设备连接仍正常时日志通道继续采集 |
| 重启 | 确认后结束此终端的Shell和前台程序，封存已有日志，重新启动Shell；其他终端继续运行 |
| 标签上的 × | 确认后结束对应Shell和前台程序、封存日志并移除标签；所有终端均可关闭 |
| 收起、切页、切标签 | 保持已连接的会话；隐藏终端仍接收输出 |
| 退出软件或断开设备 | 远端tmux会话保留，下次连接后按标签恢复；断联期间未收到的日志明确记为缺失 |

关闭最后一个终端后显示空列表，重开软件仍为空，点击“新建”才能再次创建终端。离线时不能确认终止远端会话，需先恢复设备连接。关闭不负责结束用户自行脱离Shell的后台服务，例如systemd服务、nohup或独立守护进程。

绿色栏原为tmux状态栏。本版只对软件自己的会话关闭该栏，设备名、会话标识及本次连接时间移到标签下方；连接时间为电脑时间。既有主会话继续兼容，不修改tmux全局状态栏或其他工具的会话。

终端列表保存在电脑本地的`terminals.json`，按设备分别记录；日志仍为本机UTF-8 `run.json`和`output.log`，按项目、日期归档。自动识别项目及手动指定均可用，手动项目名对各终端分别生效。关闭或重启后旧日志保留；未正常结束的命令标为中断，不伪造退出码或完整输出。

本机交付：`06-交付物/demo-v0.4.7/PortCanvas_0.4.7_x64-setup.exe`；便携版在同目录`portable/`，或使用`PortCanvas-Demo-V0.4.7-Windows-x64.zip`。安装版资料位于当前用户AppData；便携版资料与默认日志位于自身`data/`。分发包不含连接配置、密码、私钥或用户日志。

远端依赖SSH/SFTP、Bash、tmux、Python3；桌面依赖已有X11/x11vnc。当前实机范围为Windows 11 x64与Ubuntu20.04.6/ARM64控制器，其他平台未完成实机验收。设备断电、重启或程序自行退出不属于会话存活范围。
