# Demo V0.3.5 使用说明

运行 `demo-v0.3.5/win-unpacked/Wheel Combat Studio.exe`，保留整个目录。连接、远程桌面和 SFTP 操作沿用 V0.2；右侧持久终端沿用 V0.3。

1. 在设备页连接树莓派，再到桌面、文件、日志或擂台页展开右上角“终端”，点击“连接 / 恢复终端”。
2. 日志自动开始采集。终端中的“日志项目”留空时自动识别 Git 项目或当前目录；填写并点击“应用”可指定之后命令的项目名。
3. 每次前台命令返回后，左侧“日志”页面显示对应记录，包括退出码、时间、运行目录和文本。后台输出及提示符保存在“终端会话输出”记录。
4. 可按项目、日期和状态筛选，点击记录查看。详情展示本地文件路径；“打开所在目录”可找到 `run.json` 和 `output.log`，供调试者或 AI 直接读取。大日志预览末尾 256 KiB，完整采集文本仍在文件中。
5. 勾选已结束记录并点击“清理所选”，确认后删除。正在写入的日志不可选，取消确认会保留文件。

默认日志在 Windows“文档”下的 `Wheel Combat Studio/Logs`，按项目/日期/运行编号分文件夹。日志页显示实际位置，也可在断开设备后更换目录；旧目录文件保留，可再次选回。测试和交付验收记录单独放在本项目的本地测试目录，不混入用户运行日志。

收起终端栏或断开终端不停止日志采集，只要设备 SSH 仍连接。断开设备、网络中断或关闭软件后，远程 tmux 程序仍可运行；本地无法接收的输出会标明缺失，重连不会伪造完整日志。设备断电或重启会结束远程内存会话。日志中的退出码是前台 Shell 命令退出码，后台任务可能仍运行，请结合“会话输出”判断。

V0.3.5 使用新的日志终端会话，原 V0.3 会话保留；升级不自动接管旧会话中已启动程序的输出。日志文件只保存在电脑，设备不创建本功能的日志文件。日志页在设备离线、软件重启后仍可使用。

源码：`03-实现与脚本/studio`；`npm test`、`npm run pack`。设备依赖 Bash、Python3、tmux、base64；Git 用于自动项目根识别。擂台接口实时值仍是后续功能，本版不显示模拟硬件数据。
