## 通过的检查

- 自动化测试 25/25：包含原连接与 SFTP 回归，以及 SSH PTY、分块 UTF-8 输出、输入和尺寸传递、断开/恢复、过期输入拒绝、连接取消与超时。
- 打包程序 18 个关键源码/资源文件与当前工作源码逐字节一致。
- 真实打包 EXE 的 xterm 按键输入经 Electron IPC 和 SSH PTY 到达板端，中文输出正确。用独立的测试窗口运行无运动计数程序，没有运行比赛或硬件控制代码。
- 终端在桌面、文件、擂台页面可用；设备页隐藏。收起、展开和切换页面不更换当前终端通道。桌面实际画面、SFTP 目录列表与侧栏并行可用。
- 1000×680 CSS 视口检查无全页横向溢出，主区域和侧栏边界一致，终端区约 330×317；此项是浏览器 CSS 尺寸测试，不冒充原生窗口尺寸实测。
- 终端断开/恢复、设备断开/重新登录、实际结束 Studio 主进程并重启软件后，远端计数程序均保持 PID 5238，计数从 3 持续增加到 57。测试窗口已精确关闭，未结束其他会话。
- T019 板端 Codex 在用户修复网络后完成 6 条只读命令，退出 0、修改 0；tmux 路径/版本、账户 Shell 和目录访问结果与电脑端 SSH 核查一致。模型沙箱不能创建 tmux 临时目录的限制另行保留，不作为真实主机没有会话的证据。
