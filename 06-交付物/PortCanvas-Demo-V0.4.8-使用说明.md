# PortCanvas Demo V0.4.8

本版统一界面按钮、精简重复说明并移除底部状态栏，新增文件拖拽传输；设备连接、远程桌面、多终端和本地日志继续沿用。

连接设备后打开“文件”页：

- 本地文件拖到远端栏即可上传；远端文件拖到本地栏即可下载。勾选多个项目后，可一起拖动。
- 从 Windows 文件资源管理器拖入远端栏，可上传文件和文件夹。
- 拖到目标栏空白处使用当前目录，拖到文件夹行则使用该文件夹。拖动时会显示目标提示；拖回原栏或按 Esc 可放弃。
- 上传、下载、选择目录等按钮保留，支持原有键盘操作；拖拽与按钮共用进度、限速、取消和覆盖确认。

传输为复制，保留源文件。文件夹递归复制并保留空目录，不传输符号链接或特殊文件。多个不同来源的同名项目在写入前报错，避免不明确的覆盖。覆盖需确认；取消或断线保留已完成文件，只回收本次未发布的临时文件，不提供通用断点续传。

下载目标位于软件左侧本地栏；本版没有将远端文件直接拖出到资源管理器的功能。拖拽坐标已在当前Windows 11主显示器125%缩放实测，其他平台及跨显示器缩放未完成实机验收。

连接状态在右上角显示，必要错误与日志缺失提示继续保留。终端会话标识和连接时间可展开“会话信息”查看。终端标签×确认终止对应Shell及前台程序；断开、收起、切页保留程序。日志仍存电脑本地，关闭最后一个终端后不会自动创建新终端。

安装包：`demo-v0.4.8/PortCanvas_0.4.8_x64-setup.exe`；便携版在其`portable/`内，或使用`PortCanvas-Demo-V0.4.8-Windows-x64.zip`。普通安装使用当前用户AppData，便携版使用自身`data/`。分发包不含设备资料、凭据和用户日志。

当前Windows x64客户端无需Node/Rust/Python运行环境；远端需要SSH/SFTP、Bash、tmux与Python3，桌面还需已有X11/x11vnc。设备断电、重启或程序自身退出不属于会话保活范围。
