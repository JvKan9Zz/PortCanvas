# PortCanvas Demo V0.5.8 使用说明

摄像头默认关闭。在赛台页选择树莓派的视频设备与目标帧率（8 / 15 / 20 / 30 FPS），再点击开启；默认20 FPS，网络较弱或需要减少传输量时选8 FPS。实际帧率受设备、网络与电脑影响。

支持原生MJPEG且已安装FFmpeg的设备优先复制压缩帧，避免在树莓派上逐帧解码再压缩；其他情况沿用OpenCV预览。画面经现有SSH加密通道到电脑，再由仅绑定127.0.0.1、带随机路径令牌的临时通道交给WebView2显示，不向局域网开放。关闭、切页、最小化、断连与退出会回收本次采集；恢复后摄像头保持关闭。不会录像或保存相机照片。

赛台原点位于整个围墙内区域的左下角，X向右、Y向上，单位米，有效范围0–3.8。台上和台下共用一个坐标系；原图、台面比例及黄蓝出发区对齐关系保持。

本版准备好了定位输入接口，尚未实现自主定位算法。没有定位程序时显示“定位未接入”，X/Y为“—”。真实生产程序可原子更新树莓派RAM中的/dev/shm/portcanvas-pose.json；字段、坐标换算、有效期与发布辅助函数见随源码提供的《Demo-V0.5.2-定位数据接口》。超过2秒、格式错误、越界或明确丢失定位的数据不会显示为实时点位。摄像头关闭时仍可接收定位数据；最小化后暂停读取，恢复赛台页时重新观察。

原始MJPEG减少树莓派端采集CPU，但可能增加流量与部分电脑端占用。FPS为本机预览流的交付速率，不等同端到端延迟或实车识别速度。

Windows安装器允许选择安装位置，更新沿用已有目录和用户资料。Mac打开DMG后将PortCanvas拖到“应用程序”或自己的应用目录。V0.5.6起停止发布便携版，旧便携目录data/中的资料不要随程序删除。

## 连接诊断

设备页会逐步显示认证资料准备、地址解析、TCP连接、SSH密钥交换、主机身份验证、握手完成与登录认证。失败时保留当前步骤、错误及该步骤的排查方向；重试重新开始，取消连接清除本次进度。首次连接仍需确认主机指纹，等待确认不占用网络超时时间。

## 软件内更新

打开左下角“设置 → 关于”，点击“检查更新”。发现新版本后选择“下载更新”，下载期间可取消；签名校验完成后点击“安装并重启”。Windows安装版自动覆盖安装，用户配置与日志保留。Mac固定V0.5.6，不推送后续更新。安装前需完成文件传输及资料迁移。重启会断开本机连接，远端持久终端中的程序继续运行，重连后可恢复会话。

V0.5.25没有软件内安装能力，首次升级到V0.5.3需覆盖安装一次；之后可直接在软件内更新。版本以GitHub最新正式Release为准，main中尚未发布的更改不会提示更新。更新失败时保留当前程序，可重新检查与下载。

更新下载默认使用32路并发分段；服务不支持Range时自动回退到单连接。界面显示实际并发数，取消会停止本次下载。完整文件及版本签名通过校验后才能安装。

## 远程桌面

工具栏可选择画质，选择会保存并重新连接当前桌面：

| 模式 | 传输画面 | 适用场景 |
| --- | --- | --- |
| 流畅（默认） | 设备原始分辨率 | 优先刷新和输入响应 |
| 清晰 | 设备原始分辨率，较高图像质量 | 阅读小字和细节 |
| 省资源 | 按比例限制在960×540以内，不放大小画面 | 网络较弱或需要降低前端绘制负担 |

这些选项不改变设备物理屏幕的分辨率。更高帧率仍会增加活动时的CPU或流量；具体收益随画面内容、设备与网络变化。切到其他页面或最小化时，桌面采集与转发停止，SSH及持久终端中的程序继续运行；返回桌面时自动重新连接。点击“断开桌面”后不会因切页自动重连。摄像头恢复后仍需手动开启。


## V0.5.5 操作

文件页右侧选中远端文件或文件夹，点击“删除”。确认框列出目标；确认后永久删除，目录包含其中内容，符号链接只删除链接本身。可取消尚未完成的删除，但已删除的项目无法撤回；断线或失败后刷新目录核对。删除和传输不能同时进行。

桌面连接时显示客户端准备、远端服务、SSH/VNC 协商、首屏绘制与交互准备的实际阶段；收到并绘制首屏后才允许操作。修复打开文件管理器时由同步测速触发的长时间停顿。

“重启设备”取代 Ctrl+Alt+Del。确认后会结束远端程序并断开所有连接，设备启动完成后再连接。账户需具有无需交互的 sudo 重启权限；无法提交时显示错误，不索取系统密码。

终端命令框右侧的展开按钮可切换多行编辑区。展开后 Enter 换行，Ctrl+Enter 或“发送”执行；收起时 Enter 发送、Shift+Enter 换行。Tab 补全继续可用，切换终端或折叠输入区保留各自草稿。


## V0.5.6 桌面交互与 macOS

标题、按钮、导航和文件行不再产生普通网页的文本选区。输入框保留编辑菜单，日志、命令和错误信息仍可选择复制；终端使用自己的选区，远程桌面保留远端右键操作。空白处不再出现浏览器菜单。

Windows双击安装器后，按向导进入安装位置页，可直接修改路径或点击“浏览”。软件内更新不再询问位置，继续使用原安装目录；配置与运行日志独立于程序目录。

Mac版面向macOS13+，DMG同时包含Intel和Apple芯片代码；采用ad-hoc签名且未经Apple公证，首次打开可能被Gatekeeper提示未验证，需要由你按系统提示手动允许。可参考[Apple打开未验证应用的说明](https://support.apple.com/zh-cn/102445)。不要求关闭系统安全功能。Mac凭据由钥匙串保护，首次访问可能出现系统授权提示；Windows密文不能在Mac直接解密，需要重新输入。

Mac目前仅提供Demo V0.5.6这一个适配版本，后续可能等正式版推出后再继续适配；暂不跟随Windows后续Demo更新。设置页保留版本信息和仓库入口，明确提示本版没有后续自动更新。


## 日志存储上限

在“设置 → 存储 → 运行日志”填写“存储上限（MiB）”并保存，可设置 16–1048576 MiB，也可更换或打开日志目录。新配置默认 1024 MiB（1 GiB）；已有自定义上限或不限配置保持原值。留空并保存可取消上限。

启用上限后，软件按记录开始时间自动清理最早的已结束日志，为新记录腾出空间。上限统计有效记录的 run.json 和 output.log；普通文件、符号链接、包含额外文件的目录、正在记录或由其他实例使用的记录不自动删除。降低上限时会立即尝试清理，自动清理的日志无法撤回。

若空间全由受保护记录占用，本地记录会暂停并显示原因，终端程序继续运行。提高上限、清理已结束记录后重新连接终端恢复记录；暂停期间输出不能补造。封存状态及中断说明可能造成少量临时超额。多个实例共享同一目录时各自核对文件，建议只用一个实例记录。


## V0.5.8 远端运行环境

在“设置 → 存储 → 板端运行环境”选择“电脑下载后传输”（默认）或“板端自行下载”。选择会保存，影响后续环境准备；进行中的任务保持原方式。

SSH 连接并确认主机身份后，各功能按需检查远端组件。电脑下载方式下，已有组件优先复用；缺少时读取板端现有 APT 索引中的架构、版本、文件与 SHA-256 信息，由电脑从 Ubuntu 官方 HTTPS 软件源下载并校验，缓存在电脑应用数据目录的 runtime-cache，再经 SSH 传入。板端校验后仅解包到 ~/.cache/portcanvas/runtime/，验证可启动后发布。电脑下载方式下板端不调用联网下载命令。板端自行下载方式使用设备现有 APT 源执行 apt-get download，显示下载与准备状态，同样只校验、解包到用户缓存；两种方式均不执行 apt install 或 sudo，不改 SSH 服务、厂商 SDK、Python/OpenCV 或比赛程序。

顶部显示电脑下载、SSH 传输和板端校验三阶段；前两阶段按实际字节显示进度，校验阶段显示不定进度。电脑下载复用最多 32 路分段下载，服务器不支持 Range 时使用单连接；缓存命中明确标识。取消准备或断开仅停止本次准备，保留完整电脑缓存，下次重试原操作即可复用；不提供分段断点续传。

首次下载需要电脑联网；同一版本与架构的完整缓存可重复使用，板端不必联网。若 APT 索引缺失、版本在官方源已不可用或基础库不兼容，会说明失败原因，需先处理设备索引/系统环境；自动准备不替代系统安装器。板端下载方式需要设备联网。

| 页面 | 检查与处理 |
| --- | --- |
| 远程桌面 | x11vnc 及缺失依赖自动准备；仍需可用、已登录的 X11 会话与桌面授权文件 |
| 文件 | 优先使用现有 SFTP 子系统；不可用时准备用户态 sftp-server，经同一 SSH 会话使用，保留原有文件权限与传输保护 |
| 终端、日志 | tmux、Bash、base64 缺失时准备；私有运行库不写入系统，进入交互 Shell 前恢复用户原有 LD_LIBRARY_PATH |
| 摄像头 | 优先复用 FFmpeg/OpenCV，均不可用时准备 FFmpeg；缺 OpenCV 时可由 FFmpeg 编码预览，权限不足明确提示 |
| 设备指标 | 使用 Linux /proc 与 Python 标准库；失败显示真实原因，不编造指标 |
| 定位 | 继续只读已有接口文件；没有生产程序时保持未接入，不创建模拟位置 |

两种方式的自动下载范围均为创意之星 AI 控制器的 Ubuntu 20.04 ARM64；其他系统已有组件仍可复用，缺组件时需要手动准备。设备驱动、摄像头访问权限、X11 登录会话和 Python 基础解释器不通过静默系统变更来替代；需要管理员处理的情形会显示原因。


## V0.5.8 外观与设置

设置左侧分为“通用 / 存储 / 关于”。通用中选择语言、主题色彩与“浅色 / 深色 / 跟随系统”；外观用滑动分段控件切换，跟随系统会响应系统主题变化。

“非透明度”可拖动滑条，也可直接输入 0–100 的整数百分比，按 Enter 或移开焦点保存。数值越低，外层玻璃越清透；输入控件保留清晰底色，标题和未选中导航不额外铺底色。100 保持柔和的不透明观感。系统减少动态效果偏好会关闭主要动画；支持减少透明度偏好的系统可使用实色表面。

“背景”支持颜色和本地 PNG / JPEG / WebP 图片（最大 10 MiB）。颜色面板可用色盘、预设或 HEX/RGB 输入；点击“确认”保存，“取消”保留原设置。选择图片时复制到应用资料目录，不修改原图，也不上传外部服务；可移除图片或恢复默认。深色外观会压暗背景颜色/图片，恢复浅色后还原原有显示。

导航、顶部状态栏、页面与终端分别显示为圆角玻璃区域；设备列表空态居中，桌面画布四角圆角。下拉菜单、复选框、桌面连接设置展开/收起、设置开关和页面切换提供过渡。外层滚动条隐藏但滚轮和键盘滚动仍可使用。界面使用内置苹方；终端和原始日志输出使用等宽字体，中文回退苹方。

“关于”显示产品标识、版本与 GitHub 仓库入口；“检查更新”右侧可打开本地程序目录。日志位置和容量、板端组件下载方式均在“存储”中。
