# PortCanvas Demo V0.5.5 使用说明

摄像头默认关闭。在赛台页选择树莓派的视频设备与目标帧率（8 / 15 / 20 / 30 FPS），再点击开启；默认20 FPS，网络较弱或需要减少传输量时选8 FPS。实际帧率受设备、网络与电脑影响。

支持原生MJPEG且已安装FFmpeg的设备优先复制压缩帧，避免在树莓派上逐帧解码再压缩；其他情况沿用OpenCV预览。画面经现有SSH加密通道到电脑，再由仅绑定127.0.0.1、带随机路径令牌的临时通道交给WebView2显示，不向局域网开放。关闭、切页、最小化、断连与退出会回收本次采集；恢复后摄像头保持关闭。不会录像或保存相机照片。

赛台原点位于整个围墙内区域的左下角，X向右、Y向上，单位米，有效范围0–3.8。台上和台下共用一个坐标系；原图、台面比例及黄蓝出发区对齐关系保持。

本版准备好了定位输入接口，尚未实现自主定位算法。没有定位程序时显示“定位未接入”，X/Y为“—”。真实生产程序可原子更新树莓派RAM中的/dev/shm/portcanvas-pose.json；字段、坐标换算、有效期与发布辅助函数见随源码提供的《Demo-V0.5.2-定位数据接口》。超过2秒、格式错误、越界或明确丢失定位的数据不会显示为实时点位。摄像头关闭时仍可接收定位数据；最小化后暂停读取，恢复赛台页时重新观察。

原始MJPEG减少树莓派端采集CPU，但可能增加流量与部分电脑端占用。FPS为本机预览流的交付速率，不等同端到端延迟或实车识别速度。

安装模式沿用已有资料；便携目录中的portable.flag使资料、缓存和默认日志保存在同目录data/。发布包不含用户配置、密码、密钥、运行日志或相机照片。

## 连接诊断

设备页会逐步显示认证资料准备、地址解析、TCP连接、SSH密钥交换、主机身份验证、握手完成与登录认证。失败时保留当前步骤、错误及该步骤的排查方向；重试重新开始，取消连接清除本次进度。首次连接仍需确认主机指纹，等待确认不占用网络超时时间。

## 软件内更新

打开左下角设置，点击“检查更新”。发现新版本后选择“下载更新”，下载期间可取消；签名校验完成后点击“安装并重启”。安装版自动覆盖安装，便携版在原目录更新，用户配置与日志保留。安装前需完成文件传输及资料迁移。重启会断开本机连接，远端持久终端中的程序继续运行，重连后可恢复会话。

V0.5.25没有软件内安装能力，首次升级到V0.5.3需覆盖安装一次；之后可直接在软件内更新。版本以GitHub最新正式Release为准，main中尚未发布的更改不会提示更新。更新失败时保留当前程序，可重新检查与下载；便携版需有程序目录的写入权限。

更新下载默认使用32路并发分段；服务不支持Range时自动回退到单连接。界面显示实际并发数，取消会停止本次下载。完整文件及版本签名通过校验后才能安装。

## 远程桌面

工具栏可选择画质，选择会保存并重新连接当前桌面：

| 模式 | 传输画面 | 适用场景 |
| --- | --- | --- |
| 流畅（默认） | 设备原始分辨率 | 优先刷新和输入响应 |
| 清晰 | 设备原始分辨率，较高图像质量 | 阅读小字和细节 |
| 省资源 | 按比例限制在960×540以内，不放大小画面 | 网络较弱或需要降低前端绘制负担 |

这些选项不改变设备物理屏幕的分辨率。更高帧率仍会增加活动时的CPU或流量；具体收益随画面内容、设备与网络变化。切到其他页面或最小化时，桌面采集与转发停止，SSH及持久终端中的程序继续运行；返回桌面时自动重新连接。点击“断开桌面”后不会因切页自动重连。摄像头恢复后仍需手动开启。


## V0.5.5 操作

文件页右侧选中远端文件或文件夹，点击“删除”。确认框列出目标；确认后永久删除，目录包含其中内容，符号链接只删除链接本身。可取消尚未完成的删除，但已删除的项目无法撤回；断线或失败后刷新目录核对。删除和传输不能同时进行。

桌面连接时显示客户端准备、远端服务、SSH/VNC 协商、首屏绘制与交互准备的实际阶段；收到并绘制首屏后才允许操作。修复打开文件管理器时由同步测速触发的长时间停顿。

“重启设备”取代 Ctrl+Alt+Del。确认后会结束远端程序并断开所有连接，设备启动完成后再连接。账户需具有无需交互的 sudo 重启权限；无法提交时显示错误，不索取系统密码。

终端命令框右侧的展开按钮可切换多行编辑区。展开后 Enter 换行，Ctrl+Enter 或“发送”执行；收起时 Enter 发送、Shift+Enter 换行。Tab 补全继续可用，切换终端或折叠输入区保留各自草稿。
