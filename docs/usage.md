# PortCanvas v0.6.1 使用说明

[下载 Windows x64 正式版](https://github.com/JvKan9Zz/PortCanvas/releases/tag/v0.6.1)，安装后从桌面“PortCanvas”打开。应用采用 Rust/Slint、原生 VT/RFB 和 Windows 媒体能力，无需 Node.js、Rust、Python 或 WebView 运行环境。

## 安装与资料

正式版资料位于 `%LOCALAPPDATA%/PortCanvas/Stable`，与原生 Beta 的资料目录独立。首次使用时，在设备页选择“导入旧版资料”，选择包含 `devices.json` 的旧版或 Beta 资料目录，预览后确认导入。原文件、日志和素材保持保留；需要撤回时可从迁移备份恢复。

升级安装会清理 PortCanvas 旧版专属 WebView 缓存、旧版本图标和已识别的旧更新暂存文件；配置、加密凭据、终端列表、日志、背景素材及用户自建文件保留。短暂占用会自动重试；持续占用或异常目录链接会取消安装、恢复旧程序并弹出提示。安装完成后启动应用会清理已使用的更新包；仍被占用时留待下次启动处理。旧便携版的 `data/` 目录和旧安装版资料目录不要随程序删除。同一台 Windows 电脑上的加密凭据可继续按原有身份校验使用；跨电脑迁移后需要重新输入密码。

## 连接设备

设备页启动时搜索当前局域网的 SSH 服务，也可手动填写地址和端口。使用密码或私钥认证，首次连接核对主机指纹；只有勾选记住密码才保存加密凭据。

连接中显示当前步骤，成功后隐藏步骤，失败时显示具体原因；可取消或重试。“进入远程桌面”与连接操作并排。

## 远程桌面

支持流畅、清晰、省资源三档画质、适配窗口、1:1、只读和剪贴板。工具栏展开按钮在当前窗口内放大远程桌面，保留顶部工具栏和圆角画布；再次点击或按 Escape 收回。F11 单独控制应用窗口全屏。“断开桌面”统一位于更多菜单。

## 终端与程序启动

终端使用持久 tmux 会话，支持中文输入法、复制粘贴、草稿、历史和命令补全。多标签可用两侧按钮或滚轮横向浏览，切换和新建时自动显示当前标签。

默认保留长行并横向滚动，滚轮竖向浏览历史；竖向滚动条隐藏，横向滚动条保留。更多菜单可切换按窗口折行。Shift+PageUp/PageDown 浏览历史，Ctrl+Shift+Home/End 跳到历史首尾。

连接终端后，点击运行图标或在更多菜单选择“设置启动程序”，填写板端绝对路径。运行目录留空时使用程序所在目录；可自动识别 Python、Shell 或直接运行可执行文件，也可选择使用 sudo。保存并运行后，运行图标可再次启动；修改程序时重新打开设置启动程序。配置按设备保存。

## 文件与日志

文件页支持双栏 SFTP、多选、拖拽、递归传输、覆盖确认、限速和取消。仅两侧合计选中一个普通文件时启用“复制路径”，复制完整路径；目录、链接及多选不可复制。

文件和日志的左右面板可拖动调整。日志在较窄区域改为上下排列，也可拖动分隔线。查看日志时优先展示原始输出，运行信息位于下方。纯图标按钮停留片刻后显示文字说明。

## 赛台与摄像头

相机默认关闭，选择视频设备与 8/15/20/30 FPS 后开启，默认 20 FPS。离开赛台、最小化、断连或退出后回收采集，恢复时保持关闭；不录像或保存照片。支持原生 MJPEG 时优先复制压缩帧，否则使用现有 OpenCV/FFmpeg。画面通过 SSH 直接交给原生解码器。

赛台原点在围墙内区域左下角，X 向右、Y 向上，单位米，范围 0–3.8。没有定位生产程序时显示未接入，不生成模拟位置。[定位接口](pose-protocol.md)说明原子更新方式与有效期。

## 外观与组件准备

设置支持中英文、主题、浅色/深色/跟随系统、背景颜色、图片和视频。主题、外观和工作区不透明度实时应用。玻璃质量默认 Full，与不透明度分别保存；卡顿建议由用户决定是否接受。设置和确认弹窗采用较高固定不透明度。

图片、视频导入支持裁剪预览，不修改原文件。视频静音循环，可调整音量；编解码支持取决于 Windows Media Foundation 或 macOS AVFoundation。最小化会暂停背景播放。

远端功能优先使用已有 tmux、SFTP、x11vnc、FFmpeg/OpenCV。缺失组件可由电脑下载并通过 SSH 放入用户缓存，或由板端下载；自动准备目前支持 Ubuntu 20.04 ARM64。不会替换厂商 SDK、Python/OpenCV 或比赛程序。

## 更新

正式版启动时检查一次更新，也可在“设置 → 关于”手动检查。更新不会自动下载安装；下载后校验完整文件和版本签名，确认后覆盖安装并重启，配置和日志保留。正式版读取稳定通道的 `latest.json`，不接受预览版本。Beta 安装保持独立，可手动安装正式版并导入资料。

macOS 原生测试版的安装、旧版资料导入、系统安全确认与更新说明见 [Mac 说明](macos.md)。
