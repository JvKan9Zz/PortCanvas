# Demo V0.5.2 定位数据接口

本版本提供坐标系与数据接入，不实现视觉/测距融合定位算法。用户已确认当前没有定位程序，因此正常界面保持未接入，不生成演示位置。

## 坐标约定

- 原点：整个3.8m×3.8m围墙内赛台的左下角。
- X向右、Y向上，单位米；台上、台下共用此坐标系。
- 有效范围：0≤X≤3.8，0≤Y≤3.8。
- heading为可选朝向角：0度指向+X，逆时针为正；相机坐标需要先通过标定和安装关系换算。
- 界面位置图标只表达位置与朝向，不表达尚未标定的车体尺寸。

## 输入

定位程序将最新结果原子写入树莓派RAM文件 /dev/shm/portcanvas-pose.json，SSH登录用户须可读。只保存一份最新状态，不保存历史日志。建议5–10Hz更新。

~~~json
{
  "schema": "portcanvas.pose/1",
  "valid": true,
  "x": 1.25,
  "y": 2.60,
  "heading": 90,
  "confidence": 0.85,
  "timestamp": 1790000000000
}
~~~

上例仅说明格式，不是真实观测。timestamp必须由生产程序按其树莓派当前时间生成，为Unix毫秒；不能照抄示例。x/y须是有限数字，不能是文字或布尔值。heading、confidence可不提供；confidence若提供须在0–1之间，表示生产程序自己的质量估计，不是界面给出的准确率保证。

超过2秒的数据、未来时间、越界值、未知schema、格式错误不显示实时点位。算法失去定位时立即写入schema和valid:false；也可停止更新，由超时机制清除点位。

软件通过已有SSH只读观察文件，切页、断连或退出停止观察。未接入、无效、过期和断连状态分别显示；没有数据时X/Y为“—”。未启动摄像头也能接收定位数据。

高级接入可在启动客户端前设置PORTCANVAS_POSE_PATH为远端绝对文件路径。本机验收使用独立 /dev/shm/portcanvas-v052-test-pose.json，测试数据不会写生产路径，验收后删除。

## 生产程序辅助函数

03-实现与脚本/studio-tauri/examples/publish_pose.py提供publish_pose函数；它只发布调用方传入的数据，没有自动生成坐标或循环。融合算法可在得到有效X/Y后调用；丢失定位时调用publish_pose(valid=False)。按一个文件一个生产者使用。
