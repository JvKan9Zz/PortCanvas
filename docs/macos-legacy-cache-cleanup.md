# Historical macOS WebKit cache cleanup

The historical PortCanvas 0.5.95 application uses bundle identifier `io.portcanvas.app`. Its WebKit network caches are under `~/Library/Caches/io.portcanvas.app/WebKit`, with `AlternativeServices`, `NetworkCache`, `HSTS` and `CacheStorage` subdirectories. These paths were confirmed against the installed historical app and directory names; cache contents are not read by the native cleanup implementation.

The Stable native update helper can retire that exact cache tree after it authenticates the replacement archive, replaces the application and receives the replacement's rendered-frame acknowledgement. Cleanup failure does not reverse a successful application update. The helper reports the retained path and reason; the same conservative operation can be retried after the issue is resolved. Cleanup is skipped when `WCS_DATA_DIR` or `WCS_TEST_ROOT` is set, so isolated acceptance runs cannot remove the account's historical cache. Normal application startup does not delete legacy caches automatically. Beta updates do not retire this historical Stable cache.

`~/Library/WebKit/io.portcanvas.app/WebsiteData` is retained in full. It contains persistent stores such as LocalStorage, IndexedDB and media-key storage, and is not interchangeable with a network cache. Application Support directories, JSON configuration, credentials, managed media, migration backups and logs are outside the cleanup scope. Installing an application manually does not remove these originals.

Cleanup first inspects the entire candidate tree. An unknown top-level entry, possible persistent data, symbolic or hard link, special file, another owner's entry, or group/world-writable entry causes the tree to be retained and a failure to be reported. Execution reopens directories without following links, rechecks ownership and identity, and removes entries relative to held directory descriptors. A directory changed after preview is retained. Never delete the broad `Library/WebKit`, `Library/Caches` or Application Support directories to repair an update.
