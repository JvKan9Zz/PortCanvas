## 排障与修复

- tmux 对尾分号解释为命令分隔符，初始状态包被截断导致 Shell 未就绪。两次失败后检查 pane 与选项实际内容，改为整体 base64 缓存，实机验证通过；OSC 输出仍使用原字段包。
- 采用新日志会话保护 V0.3 原会话；读取缓存放在观察通道就绪后，避免准备时抓到过期状态。设备代次/序号防止旧准备结果接入新连接。
- CSS flex 覆盖 hidden 使空详情显示，以及日志页缺少边距；按真实界面结果增加明确 hidden 规则及对应留白，重新打包复核。
- UI 检查脚本曾把返回列表误当 predicate 返回值，修正取值；一次复测误连旧调试窗口，先定位并关闭仅本轮创建的测试进程，再隔离继续。原生确认等待超时后按当前实际窗口继续验证取消/确认，不重复触发删除。一次 REPL CDP 回调超时改用独立、带请求超时的 Node 检查脚本，离线重启和最终布局通过。
- 终端显示会话标识已改为实际日志会话名，新增异步准备取消后不打开过期 PTY 的测试。
