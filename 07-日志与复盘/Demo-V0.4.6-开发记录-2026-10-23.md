# Demo V0.4.6 终端交互修复

用户要求：滚轮只在本地翻动内容、不产生终端输入；侧栏可调宽并有开合动画；品牌 Logo/名称不可选择和拖走；自行检查后建 PR、合并 main。中途补充要求后续 PR 使用 Codex 代码审查面板，本次也按此执行。

范围仅当前 studio-tauri 的终端、布局、品牌选择限制及版本/交付说明。旧 Electron、日志格式、SSH/SFTP/桌面协议与历史日志不改。分支 feature/v046-terminal-interaction，基于 e732119。

## 实现与修复

本机 xterm 6.0.0 源码 CoreBrowserTerminal.ts 显示：没有 scrollback 时轮事件会转换为 ESC[A/B，鼠标协议打开时会发送鼠标报告。最初使用公开自定义 wheel 回调返回 false，实测已阻止远端字节，但鼠标模式下依赖仍会吞掉本地滚动。最终改为 terminalOutput 的捕获监听，阻止依赖接收轮事件，按标准 pixel/line/page 单位滚动本地 buffer 或侧栏。真实键盘 onData 保持原样，未过滤或删除任何实际方向键字符。

侧栏左缘 pointer capture 拖动、键盘调整和双击复位；窗口宽度限制不改变用户原本偏好，扩大后恢复。初版主区域只留440px，1000px窗口的文件按钮出现多行和路径过窄；真实截图发现后改为预留560px。使用既有 CSS Grid 和短过渡，不加动画依赖；inert/aria-hidden 保护收回状态，减少动态偏好取消过渡。品牌 CSS 及 dragstart 取消局限于 .mark/.wordmark。

## 验证过程中的问题

- 全局文档组合输出被截断，分段补读后再继续；没有据截断内容推断规则。
- T023 板端 Codex 退出0、2个命令项、0文件变更；tmux版本3.0a，沙箱两次访问 socket 被拒后停止。电脑已有 SSH 复核用户会话仍 attached、全局 mouse off/history-limit 2000；未把沙箱拒绝当成宿主不可用。
- 第一套测试错误地要求会话名含命名空间原文，实际是稳定散列；修正为核对精确散列身份。预加载拦截无法取得测试输出回调，停止该注入路线，改用真实独立会话测试。
- SSH 测试转义字符串的 unicode_escape 解码遇结尾反斜杠报错，改用 chr(27)/chr(92) 明确构造控制符；一处精确补丁因转义不匹配失败后改为按已核实行前缀的一次性 Python 修改。
- Input.insertText 不走本终端预期按键路径，改用已实测可达的按键事件。tmux 会重设外层鼠标状态，DCS 不能作为稳定开启鼠标模式的证据；改为仅对本轮独立会话启用/关闭 mouse，未改全局或用户会话选项。
- 原生布局检查在页面绑定事件前点击，出现不可用控件；等待设备资料和事件就绪后通过。页面没有溢出时不应期待滚动，后续使用明确标记的本地高度样本创建溢出，测试结束即移除。
- 真实鼠标模式下的滚轮检查揭示最初公开回调仍吞本地滚动，按上文改为捕获阶段处理；未把前期仅“零输入字节”当成完整验收。
