# Demo V0.2 文件管理与传输

用户在 V0.1 完成后明确要求继续开发文件传输并自行测试修复。V0.1 交付保留；新交付使用 V0.2。

范围：沿用已有设备 SSH 连接，在独立 SFTP 子通道浏览本地/远端目录；双栏、多选、上一级/主目录/刷新、路径输入、本地选目录、新建文件夹；文件及目录递归上传下载；总进度、当前文件、已完成数量、取消和可选限速。覆盖已有文件前逐批明确确认。

文件传输独立于远程桌面，不修改桌面协议或车辆程序。没有新建账号或导出已有密码。实时擂台仍不接入。

上传/下载先写目标目录中的专属临时文件，完整关闭后再发布为最终文件。未传完的数据不作为最终文件发布，已完成的其他文件保留；目录复制为合并，不删除目标额外文件。文件/目录类型冲突和符号链接在写入前报错；不静默漏传。大文件可限速，取消不关闭 SSH 或远程桌面。

验收：保留既有 7 项连接测试；增加真实本机 SFTP fixture 测试覆盖中文/空格、目录、二进制/空文件、覆盖确认、拒绝覆盖、取消、断线/失败和重新连接。真实树莓派测试仅写 /home/bcsh/robot-research/wheel-combat-studio 下本次专用测试目录，电脑测试数据只写本项目 05-测试与验证/local。交付 EXE 中再验证浏览与双向传输、状态和桌面回归。内容哈希用于验证传输内容，不作为无用途附加清单。
