# 视觉接口对接

接口权威草案位于独立 `visual-to-3DModel` 仓库的 `02-方案与设计/场景接口-v0.1.md`，双方通过明确版本联调；当前版本 0.1 为文档草案，没有运行时实现。

上位机消费：会话/地图 ID、来源与有效时间、自身位姿、目标列表、台边/可行驶区域和后续三维地图引用。

上位机不自行从检测框猜出绝对位置，不把未知尺度标为米；保留 observed / predicted / lost / unknown 状态。摄像头画面与场景消息使用帧 ID 关联，不要求相同刷新率。

相机只由一个采集入口持有，再向视觉和预览分发数据。UI 页面关闭可以停预览订阅，但不能关闭车载算法所需的采集。

传输协议和编码尚未确定，先固定消息语义；视频不塞入每条场景 JSON，稠密三维地图按需要更新或引用，避免重复发送完整几何。
