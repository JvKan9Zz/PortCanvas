# Demo V0.1 范围与实现

2026-10-22：用户委托选择技术栈，选择直接编码，并进一步收敛为前两页。

- 设备连接与管理：保存设备名称、地址、SSH 端口、用户名；连接、取消、断开、错误和重连。
- 远程桌面：在软件内共享板端现有 X11 会话，支持鼠标键盘、适配/原始尺寸、只读和全屏。
- 左侧从上到下保留设备、桌面、文件、实时擂台；后两项本次只标记后续版本。
- 不开发 SFTP、视频、终端、视觉算法、车辆运动或系统性能优化。

实现采用 Electron + ssh2 + noVNC。VNC 服务只监听板端回环，经 SSH 加密转发；本地 WebSocket 只绑定 127.0.0.1，使用随机会话路径。每次桌面连接拥有自己的前台 x11vnc 子进程，关闭通道即退出；不安装开机服务、不修改 Xorg/NoMachine。板端如无组件，优先在项目专用目录解包运行，保留系统软件配置。

视觉采用用户指定的左侧工具栏和明确页面，按 Windows 开发工具的固定导航、表单、状态条与大画布组织；鼠标键盘和桌面画面占主要区域。直接编码，不增加视觉方案审批。

验收：离线/错误地址/密码错误；真实 SSH 和现有桌面；鼠标键盘输入；页面切换；断开清理、重连；EXE 普通启动。性能对比与实车验收不在本次范围。
