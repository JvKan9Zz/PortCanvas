# 右侧持久终端与擂台接口区

最终范围按用户 2026-10-22 至 23 日的连续指示：终端集成在软件右侧的展开栏；桌面、文件和擂台页共享使用，设备连接页隐藏；独立分支开发并创建 PR。

左侧仍保持设备、桌面、文件、擂台四个入口。右上角“终端”按钮控制非模态侧栏，展开时主区域与侧栏并排；收起或进入设备页不结束终端通道。窄窗口下文件表隐藏修改时间列，为名称、大小及选择框保留可用空间。

终端复用现有 SSH 登录，以独立 PTY 运行 `tmux -L wcs-terminal -f /dev/null new-session -A -s <稳定会话名>`。名称由地址、端口、账户生成，不随显示名称改变。专用 tmux server 隔离用户默认 tmux 配置；客户端关闭只分离会话。新的通道代次拒绝旧输入和尺寸请求，不自动重放输入或启动用户程序。终端文本不保存到本机日志。

前端使用 xterm.js 与 FitAddon，保留中文输出、标准终端按键、尺寸变化和滚动缓冲；终端内容与远程桌面、SFTP 采用各自的 SSH 通道。后两项原有业务逻辑不因增加终端而改写。

擂台页面未来左下角区域调整为“树莓派接口实时返回值”，终端命令与日志由右侧栏承担。接口清单、单位、返回协议和刷新节奏后续按实际 SDK 与接线核实；显示真实值、更新时间与在线状态，未接入和断联时明确标记状态，不用占位数字冒充实时数据。本次只记录该设计，不采样硬件。
