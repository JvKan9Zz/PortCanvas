# 阶段路线与验收

以下为长期路线，功能全部保留。2026-10-22 用户将首版收敛为设备连接管理与完整远程桌面：Demo V0.1 已实现并完成本机真实设备检查、Windows EXE 打包。SFTP、控制台、视频、擂台与性能对照仍未实施；原阶段编号不因本次范围调整而重排。详见 `06-交付物/Demo-V0.1-验收记录-2026-10-22.md`。

同日后续 V0.2：用户追加文件传输开发，现已完成 SFTP 双栏与双向文件/目录传输，包含进度、取消、限速和覆盖确认，并完成自动测试、真实板端与交付 EXE 检查。上段是 V0.1 时点记录；当前 SFTP 已实施，SSH 控制台、视频、擂台和性能对照仍按长期路线保留。验收见 `06-交付物/Demo-V0.2-验收记录-2026-10-22.md`。

2026-10-23 V0.3 分支：已完成右侧内置持久终端，复用设备 SSH 登录、支持切页和断线后的会话恢复；25 项测试及当前设备的同 PID 持续计数、软件结束/重启恢复通过。SSH 控制台已实施。擂台左下角的接口实时返回值记录为下一步设计，视频、擂台数据接入及性能对照继续保留。

| 阶段 | 内容 | 通过依据 |
| --- | --- | --- |
| S0 | 工程建档、连接信息和接口边界 | 文档齐备；本地仓库与 GitHub 私有仓库分别核查 |
| S1 | SSH 控制台与 SFTP 文件页 | 在授权测试目录实测中文路径、上传下载、断线错误；原文件保持 |
| S2 | 视频和场景消息接入 | 视频、日志和对象状态可同时显示；回放/模拟来源显著标识 |
| S3 | 完整远程桌面集成 | 操作板端现有会话；与 NoMachine 在相同条件下进行响应和负载对照 |
| S4 | 联调、EXE 打包和使用交付 | 普通启动可用，连接信息不进仓库，离线/重连显示正确；实机结果单列 |

实现候选应优先复用成熟的远程桌面、视频和 SFTP 组件。第一步实机原型后再决定技术栈；未验证硬件编码前不宣称可用。

视觉算法可先独立回放输出，再进行板端联调。UI 演示成功不等于定位正确、车载实时性通过或实车防掉台通过。
