# 项目简报

日期：2026-10-21；项目编号：Project-016；项目：Wheel Combat Studio。

## 用户目标

将完整远程桌面、视觉调试和传文件整合为 Windows 软件，降低调试切换成本；在同网络和同任务条件下争取减小额外负载和显示延迟。

## 范围与边界

- 完整远程桌面：显示和操作板端现有桌面会话；不能把 SSH 终端充当完整远程桌面验收。
- 调试页：左侧约 1/3，上方摄像头、下方控制台；右侧约 2/3 为赛台投影，可扩展三维场景查看。
- 文件页：本地与远端目录浏览、上传、下载和传输状态，基于现有 SSH/SFTP 通道。
- 视觉定位和场景建模由另一个工程实现；接口联调属于本项目范围。
- 车辆识别与运动闭环在车上运行；上位机退出或网络断开不应成为自主运行的依赖。
- 本次授权是建立两个私有仓库及初始文档，不安装板端服务、不改既有业务代码、不运行车辆。

## 输入与输出

输入：连接配置、远程桌面会话、视频、控制台输出、视觉场景消息、用户选择的文件。输出：Windows EXE、所需板端配套程序、部署文档和验收报告。
